# Night City Arsenal

An offline Cyberpunk 2077 weapon reference and equipment planner.

- **Open:** [Night-City-Arsenal.html](outputs/Share-with-friends/Night-City-Arsenal.html). Double-click it; no installation or internet is needed.
- **Share:** [Night-City-Arsenal.zip](outputs/Share-with-friends/Night-City-Arsenal.zip). Extract it, then open the HTML inside.
- **PWA:** [deployable files](outputs/Cyberpunk-Arsenal/pwa/) or [PWA ZIP](outputs/Night-City-Arsenal-PWA.zip). These contain the app, manifest, service worker and icons. Install through Edge from an existing HTTPS host; opening this version as a local file does not install it. No hosting is configured here.

Favorites and builds stay in your browser. Keep the same file location/browser or PWA origin when updating. Before moving, export preferences from **Data notes** and builds from **Builds > Export JSON**, then import both in the new location.

This repository intentionally contains only the products and brief instructions. Both HTML files retain the existing design, data and artwork. Source code, research, old reports and duplicate builds were removed; previous development and the uncommitted working snapshot are recoverable from Git (`refs/archive/pre-product-only-cleanup`).
